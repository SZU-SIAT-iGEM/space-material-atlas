## 复现

安装锁定的开发依赖后，在项目根目录运行：

```sh
.venv/Scripts/python.exe -m unittest discover -s tests -p "test_*.py" -v
node tests/test_layout.cjs
python manage.py validate
python manage.py build
```

macOS / Linux 用 `.venv/bin/python` 替换 Windows Python 路径。构建会执行几何与阅读核心检查。容量测试只在评估引擎或拓扑变化时另行运行，避免把旧数据当成新测量。

浏览器脚本 `tests/browser_reader.js` 与 `tests/browser_studio.js` 是接收 Playwright `page` 的函数；需要可运行的静态服务和管理端，具体端口及操作注意事项见 [maintenance.md](maintenance.md)。
