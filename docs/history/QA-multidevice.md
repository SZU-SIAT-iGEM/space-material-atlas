# 多端使用验证

日期：2026-09-21。原始数据内容未修改。

## 已实现

- Pointer Events 支持单指平移、双指同时缩放和平移，以及双指抬起一指后的连续拖动；轻触与拖动分开处理。
- 拖动开始后捕获指针，处理触屏隐式捕获转移、取消、失焦和换图，避免误点与残留手势。
- 缩放围绕指针或双指中点进行，提供缩放上限、下限和全景复位。鼠标滚轮、触控板和键盘操作保留。
- Canvas 尺寸变化保留世界坐标中心与显示倍率；手机节点定位采用适合小画布的倍率，点选后尽量使节点保持可见。
- 手机竖屏底部介绍、短横屏侧栏、可折叠导航及工具、44px 主要控件、16px 输入、安全区和独立面板滚动。
- 搜索、队伍菜单和指引按 visualViewport 可见区域定位；选择搜索结果后输入框失焦；新介绍从顶部显示。
- 阅读指引包含触屏操作，展开工具步骤自动显示更多工具；退出恢复阅读位置。编辑指引继续独立。

## 验证结果

- `node scripts/test_viewport.cjs`：12 项通过，覆盖坐标换算、缩放锚点、平移与缩放组合、单／双指转换、轻触阈值、取消、近距离双指和缩放边界。
- `node scripts/test_core.cjs`：5 项通过。
- `python scripts/test_release.py`：5 项通过。
- `python scripts/build_release.py`：通过，public 仍为五个静态文件。
- app.js、experience.js、viewport.js 语法检查通过。
- 浏览器尺寸：320×568 英文、390×844 中文、844×390 横屏、768×1024 平板、1440×900 桌面，未出现页面横向溢出。
- 浏览器操作：主题切换、缩放按钮、拖动平移、拖动后的点选、介绍开关、搜索定位、更多工具、语言切换、六步阅读指引、独立编辑指引。
- 旋转后中心坐标与每像素对应的图谱尺度一致；阅读指引关闭后恢复原 viewBox 和节点选择。
- 手机编辑页输入字号为 16px，未出现页面横向溢出；浏览器未报告脚本错误。

上述为浏览器尺寸验证和手势逻辑回归，未使用实体 iOS／Android 设备。实体多点触控、系统软键盘与刘海安全区的呈现仍需实机确认。
