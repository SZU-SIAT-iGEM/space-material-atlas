## 从源码重建

在解压后的源码目录执行 `python manage.py validate` 和 `python manage.py build`。构建需要 Python 和 Node，具体版本见 README。运行 `python -m http.server 8793 --directory public` 后打开：

`http://127.0.0.1:8793/atlas.html?guide=0&lang=en&team=2026-6055&focusTeam=1&view=bioreactor`

重建不需要启动 FastAPI 管理服务。维护时编辑模块化 content 或使用后台；再次导入时编辑 plan/nodes 并重新 compile、check。不能只修改 public 成品。
