# 统一图谱 i2026.P0.2

HiZJU-China（UniCO-Fuel）与 BUCT（Air2Protein）均已应用到维护源文件 `content/teams/2026/`，并与原有队伍显示在同一份图谱中。Friskoli 的五个路线步骤已改用各自的双语工艺说明。正式统计为 38 支名录队伍、24 支已有路线、14 支等待增补，合计 180 个节点、266 条关系、86 条来源。未入名录的未来展望仍不计入这些统计。

本包中的 `source.zip` 是构建网页所需的完整源码，包含模块化内容、管理后台、前端、布局核心、依赖锁、测试和 `.gitlab-ci.yml`；现有 Wiki 的接入片段位于 `ci/wiki-integration.yml`。`static.zip` 为同一版本的静态成品。

解压源码后运行 `python manage.py validate`、`python manage.py build`，再通过静态 HTTP 服务提供 public 目录。构建无需启动后台。Wiki 部署按 README 配置 ATLAS_BRAND_URL；本次未执行远程 CI 或线上部署。

默认英文，可切换中文。队伍聚焦参数分别为 `team=2026-6273&focusTeam=1`、`team=2026-6055&focusTeam=1`、`team=2026-6100&focusTeam=1`。不指定 team 时可以从同一页面浏览全部队伍。

Friskoli 的五个步骤和平台节点均有独立双语说明，完整旧文、新文和位置见 [步骤明细](../friskoli-2026/修改明细.md)与[平台明细](../friskoli-2026/平台说明修改明细.md)。其压缩总图通过通用路线数据整理为四节点，详见[总图修订](../friskoli-2026/总图修订.md)。队伍简介保留，前端与布局没有队伍专属分支。

合并差异及事务记录见本目录 merge-review.json、applied.json；它们记录合并当时的 revision，后续文案和版本调整另有记录。最新文档刷新包为 `space-atlas-i2026.P0.2-review-docs-20261003.zip`，以 package-manifest.json 和 verification.json 说明源码、静态产物与验收对应关系。原快照不覆盖，见[人工审查](../../人工审查.md)。
