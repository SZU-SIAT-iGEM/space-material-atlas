# 图谱版本规则

版本名称为 `i年份.状态基础图轮次.提交轮次`，例如 `i2026.P0.2`。

- `i2026`：2026 年图谱。
- `P`：预发布、待审查；`R`：正式发布。
- `0`：第零轮基础图谱。
- 最后一个数字：在该基础图上的提交轮次，从 `0` 开始。

| 版本 | 内容阶段 | 状态 |
| --- | --- | --- |
| i2026.P0.0 | 2026 年以前的全部队伍，作为初始基础版 | 预发布 |
| i2026.P0.1 | 在基础版上加入 Friskoli；保留本年度待补充名录 | 预发布 |
| i2026.P0.2 | 再加入 HiZJU-China 与 BUCT | 当前人工审查版 |

本次按上述内容阶段重建三个快照，使用相同的当前维护代码；不是恢复此前开发过程中的错误文案或实验改动。

同一基础图继续提交时依次使用 `i2026.P0.3`、`i2026.P0.4`。正式发布时用对应的 `R` 名称。基础图进入新一轮时可使用 `i2026.P1.0`。版本名不可覆盖；修改已有内容后保存新的提交轮次。

发布时，版本名称写入内容配置、网页显示和源码清单。版本列表按数字排序。schema_version、第三方依赖版本与 Git commit 各自保留，不能作为图谱发布编号替换。

旧开发编号已移出当前发布列表和交付目录，其本机备份不进入源码包。维护事务记录保留，供追溯修改内容。

## 人工审查与 GitHub

当前固定 `i2026.P0.2` 供人工审查。审查后修订保存为下一次提交，再由维护者决定正式发布。公开维护仓库为 [SZU-SIAT-iGEM/space-material-atlas](https://github.com/SZU-SIAT-iGEM/space-material-atlas)，保留模块化 content、构建脚本、测试、许可证及 CI 配置。上传源码不代表内容已经通过人工审查，预发布仍使用 P 编号；参赛同步见[托管说明](hosting.md)。
