## 建议审查顺序

1. 逐队查看 Friskoli、HiZJU-China、BUCT 的中英文队伍介绍、压缩总图、完整路线与悬浮说明，核对原始提交材料。
2. 核对物质流、工艺依赖及改良线的含义；确认候选应用及未来设想没有被改写成已完成结果。
3. 试用队伍聚焦、节点搜索、缩放、连线动画与导出；在 iframe-demo.html 中测试三队单独及共同展示。
4. 在常用桌面和手机上检查显示与触控。已有自动化记录不能替代实体设备审查。

问题记录可以写成：`队伍 / 节点或页面 / 中文或英文 / 当前内容 / 建议改动`。具体文字修订在维护端应用，再输出下一次提交；不直接修改 static.zip 中生成的 HTML。
