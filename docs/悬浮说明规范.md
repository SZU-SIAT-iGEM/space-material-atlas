# 2026 年起的节点文案规范

沿用图谱原有的悬浮格式：节点名称、节点自身说明、整队项目简介、项目链接。2026 年及后续队伍使用同一套内容编写规范，无队伍专属渲染规则。

每个节点都要有独立的中英文说明，写清该节点的物质身份、工艺作用或平台机制。平台总览节点同样需要独立说明，不能复制整队简介。步骤节点描述对应步骤，整队简介概括项目目标、整体路线与应用场景。

在主路线中用来承载压缩图的节点也必须具有自己的说明。即使压缩图显示项目名称，悬浮仍沿用原有的节点说明与队伍简介组合；不能通过隐藏某一段来代替修正文案复用。

维护字段为 team.description / description_en / narrative 和 nodes[].description / description_en / narrative。同一记录的兼容字段需同步；不同节点之间及节点与整队之间避免整段复制。新增队伍导入时检查所有节点，包括路线之外的平台节点。

新增年份沿用同一规范。通过管理端检查双语兼容字段，并在总图和相关主题图核对节点说明。
